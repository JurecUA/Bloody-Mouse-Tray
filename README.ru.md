# Bloody Mouse Tray

[English](README.md) | **Русский**

Индикатор уровня заряда и частоты опроса для беспроводной мыши **Bloody SG5 Pro (8K)** в системном трее Windows 11.

**Репозиторий:** [JurecUA/Bloody-Mouse-Tray](https://github.com/JurecUA/Bloody-Mouse-Tray)  
Форк / модификация на основе [Fan4Metal/mouse_tray](https://github.com/Fan4Metal/mouse_tray); поддержка ведётся исключительно для этой модели мыши
(донгл `1956:3069`, кабель `1956:3144`). Bloody Central держать запущенным не требуется.

## Bloody Mouse Tray Light (Rust)

Нативная версия для Windows на Rust. Показывает заряд батареи, частоту опроса и DPI мыши Bloody SG5 Pro в системном трее. Поддерживает русский, украинский и английский интерфейс, портативные настройки и необязательный автозапуск вместе с Windows.

- [Скачать готовый Bloody Mouse Tray Light.exe](bloody-mouse-tray-light/release/Bloody%20Mouse%20Tray%20Light.exe)
- [Исходники и инструкция по сборке](bloody-mouse-tray-light/README.ru.md)
- Файл настроек `mouse_tray.json` должен находиться рядом с `.exe`; готовый набор настроек включён в папку `release`.

## Возможности оригинальной Python-версии

- **Уровень заряда в трее:** отображается цифрами или иконкой батареи. Иконка анимируется во время зарядки. Мышь опрашивается каждые `Poll interval`
  (по умолчанию 60 секунд); только раз в секунду, если мышь спит или не найдена. Клик или наведение на иконку считывают мышь немедленно.
- **Наведение на иконку:** при наведении на иконку отображается текущая частота опроса, окрашенная в соответствии со встроенной LED-схемой мыши. При уходе курсора возвращается уровень заряда. Метки: `125`, `250`, `500`, `1K`, `2K`, `4K`, `8K`.

  | Частота | Цвет | | Частота | Цвет |
  |---|---|---|---|---|
  | 125 | фиолетовый | | 2000 | зелёный |
  | 250 | серый (отсутствует на реальной мыши) | | 4000 | жёлтый |
  | 500 | бирюзовый | | 8000 | синий |
  | 1000 | белый | | | |

  Цвета взяты из раздела «Report Rate Adjustable» руководства; значения RGB приблизительные (`RATE_COLORS` в
  `mouse_tray/config.py`). Иконка частоты учитывает настройку **Text outline**; без обводки белый 1000 Гц не виден на светлой панели задач.
- **Подсказка:** название мыши, время с последней полной зарядки, частота опроса и DPI. Процент показывается только в режиме «иконка батареи» (поскольку на самой иконке цифр нет).
- **Таймер полной зарядки:** запускается, когда заряд достигает 100%, в том числе если мышь заряжалась при выключенном компьютере: программа запоминает последний замеченный уровень и при запуске определяет скачок до 100%. В этом случае время отсчитывается с первого опроса после загрузки. Ложные показания 100% сразу после отключения кабеля во время зарядки (особенность прошивки) игнорируются. Контекстное меню в трее (правый клик) оформлено в том же тёмном стиле, что и настройки: **Reset timer** вручную сбрасывает таймер, далее — Settings, About и Exit.
- **Кабель и донгл одновременно:** при подключённом кабеле сначала опрашивается проводная мышь; донгл остаётся резервным вариантом (при подключённом кабеле донгл сообщает «no connection»).
- **Портативность:** настройки, дата полной зарядки и последний уровень заряда хранятся в `mouse_tray.json` рядом с приложением. Логи (`logs\app.log`) пишутся только при включённом **Debug logging**; если он выключен, ни файл, ни папка не создаются (предупреждения выводятся только в консоль, если она доступна). Программа не использует `AppData`; она лишь пишет опциональную запись автозапуска в реестр (см. ниже) и читает список системных шрифтов для настроек.
- **Автозапуск:** флажок **Start with Windows** в настройках добавляет запись в
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (указывая на текущий путь к исполняемому файлу). Если переместить папку программы, нажмите OK в настройках с установленным флажком, чтобы обновить путь. Кнопка **Reset to defaults** не влияет на автозапуск.
