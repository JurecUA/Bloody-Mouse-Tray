# Bloody Mouse Tray

[English](README.md) | [Русский](README.ru.md) | **Українська**

Індикатор рівня заряду та частоти опитування для бездротової миші **Bloody SG5 Pro (8K)** у системному треї Windows 11.

**Репозиторій:** [JurecUA/Bloody-Mouse-Tray](https://github.com/JurecUA/Bloody-Mouse-Tray)  
Форк / модифікація на основі [Fan4Metal/mouse_tray](https://github.com/Fan4Metal/mouse_tray); підтримується лише ця модель миші
(донгл `1956:3069`, кабель `1956:3144`). Bloody Central не потрібно залишати запущеною.

## Можливості

- **Мови інтерфейсу:** англійська, російська та українська. Виберіть мову в **Налаштування → Система → Мова**; вибір зберігається разом з іншими налаштуваннями.

- **Рівень заряду в треї:** відображається цифрами або іконкою батареї. Іконка анімується під час заряджання. Миша опитується через кожен `Poll interval`
  (за замовчуванням 60 секунд); лише раз на секунду, якщо миша спить або її не знайдено. Клацання чи наведення на іконку зчитує дані з миші негайно.
- **Наведення на іконку:** під час наведення відображається поточна частота опитування, забарвлена відповідно до вбудованого індикатора миші. Коли курсор відходить, знову показується рівень заряду. Позначення: `125`, `250`, `500`, `1K`, `2K`, `4K`, `8K`.

  | Частота | Колір | | Частота | Колір |
  |---|---|---|---|---|
  | 125 | фіолетовий | | 2000 | зелений |
  | 250 | сірий (на реальній миші відсутній) | | 4000 | жовтий |
  | 500 | бірюзовий | | 8000 | синій |
  | 1000 | білий | | | |

  Кольори взято з розділу «Report Rate Adjustable» посібника; значення RGB приблизні (`RATE_COLORS` у
  `mouse_tray/config.py`). Іконка частоти враховує параметр **Text outline**; без контуру білий колір для 1000 Гц не видно на світлій панелі завдань.
- **Підказка:** назва миші, час від останнього повного заряджання, частота опитування та DPI. Відсоток показується лише в режимі «іконка батареї» (адже на самій іконці цифр немає).
- **Таймер повного заряджання:** запускається, коли заряд досягає 100%, зокрема якщо миша заряджалася, поки комп’ютер був вимкнений: програма запам’ятовує останній відомий рівень і під час запуску визначає його стрибок до 100%. У цьому разі відлік починається з першого опитування після запуску системи. Хибні показники 100% одразу після від’єднання кабелю під час заряджання (особливість прошивки) ігноруються. Контекстне меню в треї (права кнопка миші) оформлене в тому самому темному стилі, що й налаштування: **Reset timer** скидає таймер вручну; далі доступні Settings, About і Exit.
- **Кабель і донгл одночасно:** коли під’єднано кабель, спочатку опитується дротова миша; донгл залишається резервним варіантом (під’єднаний кабелем донгл повідомляє «no connection»).
- **Портативність:** налаштування, дата повного заряджання й останній рівень заряду зберігаються у `mouse_tray.json` поруч із програмою. Журнал (`logs\app.log`) записується лише коли ввімкнено **Debug logging**; якщо його вимкнено, не створюються ані файл, ані папка (за наявності консолі попередження виводяться лише до неї). Програма не використовує `AppData`; вона записує лише необов’язковий параметр автозапуску в реєстр (див. нижче) і читає список системних шрифтів для налаштувань.
- **Автозапуск:** прапорець **Start with Windows** у налаштуваннях додає запис до
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (із шляхом до поточного виконуваного файла). Якщо перемістити папку програми, натисніть OK у налаштуваннях із позначеним прапорцем, щоб оновити шлях. Кнопка **Reset to defaults** не змінює автозапуск.

## Запуск з вихідного коду

Потрібна 64-бітна Windows 11 і Python 3.11+ (у проєкті закріплено Python 3.14).

```powershell
uv sync
uv run python main.py
```
